# Анастасия и Вячеслав · 30.01.2027

Свадебное приглашение: https://nicl4m.github.io/anastasia-vyacheslav-wedding/

Статический сайт на HTML, CSS и JavaScript. Шрифты и фотографии хранятся в `assets/`; внешние сервисы для отображения приглашения не нужны.

GitHub Pages: публикация из ветки `main`, папка `/ (root)`.

- `index.html` — тексты приглашения и разметка.
- `styles.css` — оформление и адаптация для телефонов.
- `config.js` — ссылки на анкету гостя и Telegram организатора.
- `script.js` — ссылки и обратный отсчёт.
- `assets/` — изображения, шрифты и их лицензии.

Изменения в `main` автоматически публикуются через GitHub Pages. Личные печатные приглашения и служебные файлы прежнего хостинга сюда не включены.
